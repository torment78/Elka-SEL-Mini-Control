# Application icon

`ElkaMiniControl.png` contains the application artwork. `ElkaMiniControl.ico`
contains transparent 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel frames for
Windows Explorer, the window title bar and the system tray.

Rebuild the ICO with `tools/BuildIcon.ps1` from the repository root
using Windows PowerShell.
